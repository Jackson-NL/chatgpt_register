## 已解决的问题

### 1. SMSBower 接码模块
- **问题**：httpx 在 Camoufox 浏览器运行期间会走系统代理(Clash 7890)，导致 SMSBower API 请求 `ConnectError`
- **解决**：`backend/app/services/smsbower.py` 改用 `curl.exe -x http://127.0.0.1:7890` 通过 subprocess 调用，避开 httpx 的代理问题
- **当前状态**：`get_number`/`get_status`/`set_status`/`get_balance` 均正常工作

### 2. OAuth token 交换
- **问题**：`exchange_code()` 使用 httpx 时也遇到代理冲突
- **解决**：改用 httpx 默认行为（走系统代理，通过 Clash 的美国节点访问 OpenAI）
- **当前状态**：待验证（代码已就绪，但还没走到这一步）

### 3. 页面加载
- **问题**：`page.wait_for_load_state("networkidle")` 超时（sentinel SDK 持续发请求）
- **解决**：改为 `wait_until="domcontentloaded"` + 等待 2 秒
- **当前状态**：页面可正常加载到 `/log-in`

### 4. 配置文件
- `MAX_PRICE` 从 `0.05` 提高到 `0.2`（0.05 时 SMSBower 返回 NO_NUMBERS）

## 当前核心卡点

### 已修复：手机号国家代码选择

**现象**：
- 点击 "Continue with phone" 后，国家代码默认是 **Singapore (+65)**
- 填入的哥伦比亚号码 (57xxxx) 被验证为 "Phone number is not valid."
- 因为组件自动拼接成 +65xxxxxxxx，与实际号码不匹配

**页面结构（已通过真实浏览器验证）**：
1. 登录页：`https://auth.openai.com/log-in`
2. 默认显示 email 输入框
3. 需点击 "Continue with phone" 按钮切换到手机号模式
4. 手机号输入组件结构：
   - 可见输入框：`input[type="tel"][id="tel"]`（placeholder="Phone number"）
   - 隐藏表单字段：`input[name="phone"][type="hidden"]`
   - 国家代码选择器：React ARIA Select 组件，由 `button[aria-haspopup="listbox"]` 触发
   - 下拉选项：`[role="option"][data-key="CO"]`（哥伦比亚的 data-key 是 "CO"）
   - 隐藏后备 `<select>` 元素：`<select tabindex="-1">` 内有 `<option value="CO">`
5. "Continue" 按钮：`button[type="submit"][name="intent"][value="phone_number"]`

**已尝试的修复方案及失败原因**：

| 方案 | 结果 | 原因 |
|---|---|---|
| Playwright 原生 `click()` | Timeout | Camoufox 下 Playwright 点击操作一直卡在 "performing click action"（`force=True` 也无效） |
| `page.evaluate` JS 点击按钮 | 成功触发 | 但下拉选项是虚拟滚动（233 项），CO 在第 42 位，不在可见 DOM 中 |
| `page.evaluate` 查找 `[data-key="CO"]` | 找不到 | 选项未渲染到 DOM |
| 滚动下拉列表找到 CO | 待验证 | 需用 JS 设置 hidden `<select>` 的 value 并 dispatch change 事件 |

**实现与验证**：
- `registrator.py` 用 `HTMLSelectElement.prototype.value` 原生 setter 设置 `CO`，并派发 `input` 与 `change`，不依赖虚拟列表中是否渲染该选项。
- 号码先规范化为完整 E.164 值和本地号码；不再使用会误删数字的 `lstrip("+57")`。
- 填写后读取 `input[name="phone"]`，仅当其精确等于预期 E.164 值时才提交表单。
- Camoufox 离线冒烟已验证 `CO` 与本地号码 `3181624184` 同步为 `+573181624184`。

### 次要问题

## 本次验证记录

- 本地 OAuth 回调监听器已加入，限制为 `localhost`/loopback HTTP 回调，且只接受与本次 PKCE 流程相同的 `state`。
- 回调 URL 同时从 request、response、主 frame 导航和本地监听器捕获，避免回调端口无服务时遗漏授权码。
- 普通 Playwright click 失败时，按钮操作会退回到该元素的 DOM `click()`；手机号表单会识别页面提供的 `window.__submitPendingForm()` 提交钩子。
- 提交手机号、密码和 OTP 后均等待 URL 状态变化；状态没有推进时，返回页面告警而不是继续轮询 SMS。
- 接码状态异常、OTP 超时或浏览器错误会释放激活号；验证码成功提交后标记为已完成。
- 后端 `http://127.0.0.1:8000/`、`/docs` 与前端 `http://[::1]:5173/` 均返回 HTTP 200；前端生产构建成功。
