## 三层健壮性架构（新增）

### 第一层：页面状态探测器（每步之间主动"看"页面）
- `probe_page(page)`：主动读取 URL/标题/错误文本 → 返回状态信号 dict
- `classify_page(url, title)`：把页面分类为阶段（email_verification / set_password / about_you / chatgpt_home / cloudflare_challenge / page_error ...）
- `expect_phase()` / `wait_for_phase()`：断言/等待页面进入预期阶段

### 第二层：异常即状态信号（观察到异常 → 抛特定异常）
| 异常 | 触发条件 |
|---|---|
| `CloudflareChallengeError` | "Just a moment" / Oops error / 403 challenge |
| `WrongPhaseError` | 页面阶段与预期不符 |
| `PageStuckError` | 页面卡住/未跳转 |
| `VerificationTimeoutError` | 验证码轮询超时 |
| `EmailDomainBlockedError` | Continue with password 缺失（域名被限流信号） |
| `TokenExtractError` | access_token 提取失败 |

### 第三层：worker 循环按异常类型"调整"
`register_by_email()` 的循环按异常类型差异化处理：
- **Cloudflare 拦截** → 等待 45s+30s×attempt 降温后换新邮箱重试
- **域名限流** → 等待 60s+60s×attempt 换新邮箱重试
- **验证码超时** → 直接换新邮箱重试
- **页面阶段异常/token 提取失败** → 换新邮箱重试

## 2FA (TOTP) 绑定 —— 纯 API 方式（新增，已验证）

在注册成功拿到 access_token 后，不依赖页面点击，直接调 OpenAI 内部 API 绑定 TOTP 二次验证：

`
POST /backend-api/accounts/mfa/enroll
  body: {"factor_type": "totp"}
  → 200 {"secret":"<base32>","session_id":"<sid>","factor":{"id":"<fid>","factor_type":"totp",...}}

(本地) pyotp.TOTP(secret).now() → 6 位验证码

POST /backend-api/accounts/mfa/user/activate_enrollment
  body: {"code":"<totp>","factor_type":"totp","session_id":"<sid>"}
  → 200 {"success":true}

GET  /backend-api/accounts/mfa_info
  → {"mfa_enabled":true,"mfa_enabled_v2":true,
     "native_default_factor_id":"<fid>","factors":{"totp":[...]}}
`

- 端点名来自 chatgpt.com webapp JS bundle 挖掘（probe_mfa_endpoints*.py）
- 交付结果新增 	otp_secret 字段（base32 secret，可用于 2fa.show 或本地 pyotp 生成动态码）
- 验证记录：完整注册 → enroll → activate 200 → mfa_info 确认已启用，一次通过

## 登录页卡死根因与修复（新增）

**现象**：邮箱提交后停在 chatgpt.com/auth/login?email=...，输入框为空、无报错。
**根因（探针实测）**：React 未水合时点击提交走原生表单 GET → 整页导航中断 JS chunk
（NS_BINDING_ABORTED）→ 二次加载 CSP nonce 不匹配停在静态壳。
**修复**：
- 交互前 wait_spa_ready()：networkidle + 人性化停顿，确保 React 挂上 onSubmit
- submit_email_with_recovery()：识别原生回退特征（chatgpt.com/auth/login + ?email= + 空输入框）
  → 自动 reload 恢复并重填重提
- pick_visible()：Continue with password 等文本元素取第一个可见的（避免隐藏副本）
- 设密码后 / about-you Finish 提交偶发未跳转 → 增加重试
