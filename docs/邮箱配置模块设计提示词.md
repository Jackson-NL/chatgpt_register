已知 API：

- 创建邮箱：
  - `POST /api/new_address`
  - body：`{ "name": "<name>", "domain": "<domain>" }`
  - 返回包含：`address`、`jwt`、`address_id`
- 地址设置/凭证验证：
  - `GET /api/settings`
  - Header：`Authorization: Bearer <JWT>`
- 读取解析后邮件列表：
  - `GET /api/parsed_mails?limit=<limit>&offset=<offset>`
  - Header：`Authorization: Bearer <JWT>`
- 读取单封解析邮件：
  - `GET /api/parsed_mail/:id`
- 私有站点访问密码：
  - Header：`x-custom-auth: <SITE_PASSWORD>`
- 常见错误：
  - `401 InvalidAddressCredentialMsg`：JWT 错误/过期。
  - `401 CustomAuthPasswordMsg`：站点需要 `x-custom-auth`。
  - `429`：限流，需要退避重试。
