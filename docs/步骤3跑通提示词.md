## 已确认的关键事实(不要改,直接用)

### OAuth 协议(sub2api 源码验证过的官方 Codex CLI 流程)
- authorize:`https://auth.openai.com/oauth/authorize`
- token:`https://auth.openai.com/oauth/token`
- client_id:`app_EMoamEEZ73f0CkXaXp7hrann`(Codex CLI 官方)
- redirect_uri:`http://localhost:1455/auth/callback`
- scope:`openid profile email offline_access`
- PKCE:code_verifier = 48 随机字节 base64url;code_challenge = SHA256(verifier) base64url(无 padding)
- authorize 额外参数:`id_token_add_organizations=true`、`codex_cli_simplified_flow=true`
- token 交换表单:`grant_type=authorization_code&client_id=...&code=<授权码>&redirect_uri=...&code_verifier=...`
- token 响应含 `access_token`/`refresh_token`/`id_token`/`expires_in`
- 账号信息从 `id_token` 的 `https://api.openai.com/auth` claims 提取:`chatgpt_account_id`/`chatgpt_user_id`/`chatgpt_plan_type`

### 手机号注册流程(抓包确认)
1. 打开 authorize URL → 302/JS 跳转到登录/注册页
2. 输入手机号(如 +57xxxx)→ Continue
3. 新账号:设置密码
4. 手机 OTP 验证码 → 输入 → 验证
5. 完成 OAuth 回调,跳回 `http://localhost:1455/auth/callback?code=...&state=...`
6. 用 code 换 token

### sentinel 风控
- 每个业务请求前需 `POST sentinel.openai.com/backend-api/sentinel/req` 取 token(flow 如 `username_password_create`/`verify_phone_otp`)
- token 内嵌浏览器行为指纹,**纯 HTTP 模拟不可行** → 必须走真实浏览器(Camoufox)让页面自己完成,不要尝试伪造

### SMSBower 接码(backend\app\services\smsbower.py 已可用)
- 取号:`get_number()` 返回 `(activation_id, phone)`,取号后需 `set_status(activation_id, 1)`(号码就绪)
- 轮询:`get_status(activation_id)` 返回 `("code", "123456")` 或 `("wait", "")`
- 完成:`set_status(activation_id, 6)`;失败:`set_status(activation_id, 8)`
- **请求必须带浏览器 UA**,否则 403(模块已处理)
- country=33(哥伦比亚),maxPrice=0.05,service=dr

## 当前卡点与你的任务

### 卡点 A:代理(必做,否则 OpenAI 地区限制拦截)
**本机大陆 IP 被 OpenAI 拒绝**(authorize 返回 `unsupported_country_region_territory`)。Camoufox 必须走海外代理。

**两种方式(选能用的)**:
1. 本机全局代理(Clash,端口 **7890**):Camoufox 配置 `proxy={"server":"http://127.0.0.1:7890"}`(已验证该端口可达 OpenAI)
2. Cliproxy 认证代理(如果用户提供了新会话):`http://user:pass@us.cliproxy.io:443`,Camoufox 配置 `proxy={"server":"http://us.cliproxy.io:443","username":"...","password":"..."}`

验证代理连通性:用该代理 curl `https://httpbin.org/ip` 应返回非中国 IP。**先验证代理,再跑注册,避免浪费接码余额。**
